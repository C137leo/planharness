## 0. 设计原则

- **Console 是工程驾驶舱**：信息密度高，强调 trace、diff、指标；不是给终端用户看的。
- **用户端是安静的教练**：卡片少、字少、每屏一个主行动。
- **不做成医疗仪表盘**：避免红十字、病历、诊断感；用运动/生活化的视觉语言。
- **所有数字可追溯**：计划/餐食/补丁旁能看到“依据”和“更新时间”。
- **安全提示必须显眼**：红灯/过敏/禁忌不能被折叠。

## 2. Web Console：Run 详情

```text
┌──────────────────┬────────────────────────────────┬──────────────────┐
│ Trace 时间线     │ 节点详情                       │ 计划 Diff / 状态 │
│                  │                                │                  │
│ ● load_plan      │ safety_gate                    │ v1 → v2          │
│ ● safety_gate    │ 结果：block / pass             │ 变更 3 / 12      │
│ ● propose_patch  │ 命中：膝痛-高冲击               │ churn 25%        │
│ ● validate_patch │ 原因：跑步、深蹲对膝关节冲击高  │ 保留 9 / 12     │
│ ● compute_diff   │ 替代：快走、臀桥               │                  │
│ ● approval       │                                │ [通过] [拒绝]    │
│ ● commit         │ [查看原始模型输出]              │ [回滚到 v1]      │
└──────────────────┴────────────────────────────────┴──────────────────┘
```

**三个区域**

1. **Trace**：节点状态（成功/拦截/等待/失败）、耗时、token；点击节点看输入输出。
2. **节点详情**：检索文档、模型原始 JSON、校验器命中规则、diff 计算过程。
3. **状态/Diff**：旧版 vs 新版、churn、未变更比例、审批按钮、回滚按钮。

**关键状态**

- `running`：节点闪烁/进度。
- `waiting_approval`：黄色横幅 + 审批按钮。
- `blocked`：红色安全提示，不可提交。
- `committed`：绿色，显示版本号。
- `failed`：失败标签 + 重试按钮。

## 4. Web 用户端

### 4.1 引导

```text
┌────────────────────────────────────────────┐
│ 第 1 步 / 共 4 步                          │
│ 你的目标是什么？                           │
│ [减脂] [维持] [增肌（即将开放）]           │
│ 目标体重 [ 65 ] kg   周期 [ 4 ] 周         │
│                              [下一步]      │
└────────────────────────────────────────────┘
```

- 4 步：目标 → 身体/活动量 → 偏好/过敏 → 训练条件。
- 每步可返回；最后一屏显示摘要。
- 安全筛查在提交后执行，红灯直接阻断。

### 4.2 计划

```text
┌────────────────────────────────────────────┐
│ 你的 4 周计划        v1        [确认计划]  │
├────────────────────────────────────────────┤
│ 第 1 周  训练 3 次  快走 2 次               │
│ [周一 下肢] [周三 上肢] [周六 全身]         │
│ 热量 1800 kcal   蛋白质 120g                │
│ 餐食建议：早餐 / 午餐 / 晚餐                │
│ [换一个动作] [调整训练日]                   │
└────────────────────────────────────────────┘
```

- 动作卡显示：动作名、组数/次数、时长、替代动作。
- 餐食卡显示：食物、份量、热量、蛋白质、过敏原。
- 确认后锁定 v1；修改走补丁/审批。

- 待审批补丁时顶部显示黄色横幅。
- 安全红灯时显示红色卡片，禁用训练入口。

### 4.4 进展

- 体重折线图（7 日均线）。
- 执行率环图。
- 周复盘卡片：趋势、建议、接受/修改。
- 版本历史入口。

## 6. 组件清单

| 组件 | 用在哪 | 说明 |
| --- | --- | --- |
| `TraceTimeline` | Console | 节点状态、耗时、点击详情 |
| `PlanDiffList` | Console/用户端 | 旧值→新值、原因、保留比例 |
| `MetricTile` | Console | 大数字 + 阈值 + 状态 |
| `ConfigMatrix` | Console | A/B/C 对比表 |
| `FailureList` | Console | failure tag + trace 链接 |
| `PlanDayCard` | 用户端/小程序 | 一天的训练/餐食 |
| `CheckinForm` | 用户端/小程序 | 体重/睡眠/饥饿/酸痛/执行率 |
| `ApprovalCard` | 用户端/小程序 | diff + 通过/拒绝 |
| `WeightChart` | 用户端 | 7 日均线 |
| `SafetyBanner` | 全局 | 红灯/黄灯提示 |
