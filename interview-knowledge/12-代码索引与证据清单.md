## 按需重现

在backend目录、隔离环境执行，例如：

```bash
uv run pytest tests/test_semantic_binding.py::test_confirm_and_new_requirement_have_explicit_task_handoff
uv run pytest tests/test_revision_goal_contract.py
uv run pytest tests/test_capability_migration_contract.py
```

前端普通测试为`node --test tests/*.test.cjs`，浏览器脚本需要对应隔离服务和Chrome，不能直接当单元测试混跑。真实模型评测另需成本/凭证/数据边界，不能为了面试演示直接创建真实订单。完整开发步骤见 [DEVELOPMENT](../docs/DEVELOPMENT.md)。
